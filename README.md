project 23-KCVN-SPM-BE

- Framework: Spring Boot
- Language: Kotlin
- JDK: 17
- DB: PostgreSQL 15
- Migration: Flyway 9.20.0
- Data access layer: jOOQ
- Builder: Maven

Commands:
- Init/Migrate DB: `mvn -Dflyway.configFiles=src/main/resources/application.properties flyway:migrate`
- Generate models: `mvn clean install`
- Run project: `mvn spring-boot:run`

NOTE: check for DB info in src/main/resources/application.properties. package model is in .gitignore because it will be generated by jOOQ.
